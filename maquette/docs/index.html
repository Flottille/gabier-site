Getting started

Put Pince on watch in two minutes

Gabier is a small Rust daemon that follows your sshd logs and sends a notification to Discord or Slack whenever a login is accepted. This page takes you from zero to a running service.

Linux · systemd Rust 1.75+ root for /etc

01Install

From crates.io, or build from source. Either way you end up with one static binary.

shell
$ cargo install gabier
$ sudo install -m755 ~/.cargo/bin/gabier /usr/local/bin/gabier

No Rust on the server? Build on your machine with cargo build --release --target x86_64-unknown-linux-musl and copy target/…/gabier over. Prebuilt binaries will be on the releases page.

02Configure

Generate the example config, then paste at least one webhook. The file holds a secret, so keep it 600.

shell
$ sudo mkdir -p /etc/gabier
$ gabier init | sudo tee /etc/gabier/config.toml >/dev/null
$ sudo chmod 600 /etc/gabier/config.toml
$ sudoedit /etc/gabier/config.toml

A minimal config looks like this:

/etc/gabier/config.toml
# hostname = "vps-01"      # defaults to /etc/hostname

[events]
accepted = true
failed = false
ignore_ips = ["203.0.113.7"]   # your static IP

[discord]
webhook_url = "https://discord.com/api/webhooks/…"
mention = "@here"

Then check it and fire a test notification on every configured channel:

shell
$ sudo gabier check
$ sudo gabier test
Notification de test envoyée sur discord.
Pince te fait coucou depuis la hune.

03Run as a service

The shipped unit runs Gabier as a dynamic user with a read-only system and no capabilities. It only needs to read the journal and reach HTTPS.

shell
$ sudo install -m644 gabier.service /etc/systemd/system/
$ sudo systemctl daemon-reload
$ sudo systemctl enable --now gabier
$ journalctl -fu gabier

Now open an SSH session from another machine. Pince should shout in your channel within a second. If nothing shows up, jump to Troubleshooting.

Reference

Configuration

Unknown keys are rejected, so a typo fails loudly at gabier check rather than silently at 3 am.

KeyDefaultDescription
hostname/etc/hostnameName shown in notifications.
source.kind"journald"journald follows journalctl -f; file tails a log file, rotation aware.
source.units["ssh.service", "sshd.service"]systemd units to follow (journald only).
source.path—Log file to tail (file only): /var/log/auth.log, /var/log/secure.
events.acceptedtrueNotify accepted logins.
events.failedfalseNotify failed attempts. Noisy on an exposed VPS; pair with fail2ban.
events.disconnectedfalseNotify disconnects.
events.ignore_users[]Users to stay quiet about (a backup account, for instance).
events.ignore_ips[]Source IPs to stay quiet about (your static IP).
discord.webhook_url—Discord webhook. Secret.
discord.username"Gabier"Bot name shown in Discord.
discord.avatar_url—Public PNG for the avatar. Put Pince there.
discord.mention—<@id>, <@&role> or @here, on accepted logins only.
slack.webhook_url—Slack incoming webhook. Secret.
slack.channelwebhook defaultTarget channel, e.g. "#server-alerts".
slack.mention—<@U…>, <!here> or <!subteam^S…>, on accepted logins only.

At least one of [discord] and [slack] must be present. Both may be.

Events

Gabier recognizes three sshd log lines. Everything else is ignored.

Accepted Accepted publickey for alice from 203.0.113.7 port 51234 ssh2: ED25519 SHA256:…
Failed Failed password for invalid user admin from 203.0.113.9 port 2222 ssh2
Disconnected Disconnected from user alice 203.0.113.7 port 51234
Channels

Discord

  1. Open the channel settings → Integrations → Webhooks → New webhook.
  2. Name it Gabier, upload Pince as the avatar, copy the webhook URL.
  3. Paste it as discord.webhook_url. Run gabier test.

Slack

  1. Create an app at api.slack.com/apps → Incoming Webhooks → turn it on.
  2. Add New Webhook to Workspace, pick the channel, copy the URL.
  3. Paste it as slack.webhook_url. Messages use Block Kit with a plain-text fallback for push notifications.

Troubleshooting

Nothing shows up after a login

Run RUST_LOG=gabier=debug gabier watch in a terminal and log in again. If no lines appear, the source is wrong: check systemctl status ssh sshd for the real unit name, or switch to kind = "file".

journalctl: permission denied

The unit adds the systemd-journal group. If you run Gabier by hand, use sudo or add your user to that group.

Discord replied 401 / 404

The webhook was deleted or the URL is truncated. Create a new one and paste the whole URL, token included.

Too many messages

Set events.failed = false, add your IP to ignore_ips and your automation accounts to ignore_users. Burst dedup is on the roadmap.
