Features

Everything a lookout needs. Nothing he doesn't.

Gabier is deliberately small. Here is the full list of what it does, and a few things it refuses to do.

01 · Real time

Within a second of the login

Gabier streams the sshd journal (journalctl -f) or tails a log file with rotation handling. There is no polling interval to tune: a line is read the moment sshd writes it, and the webhook request leaves on a separate task so a slow Discord never blocks the next line.

20:01:02.114 sshd: Accepted publickey for thibault from 203.0.113.7 …
20:01:02.118 gabier: event detected  user=thibault ip=203.0.113.7
20:01:02.391 gabier: discord notification sent  273 ms
Discord

Rich embed, colored by event. Custom name and avatar. Mention a user, a role or @here.

Slack

Block Kit message with a plain-text fallback for push. Target channel override. <!here> and user-group mentions.

Telegram · ntfy · email

On the roadmap. The Notifier trait is one file per channel.

02 · Channels

Discord and Slack, by webhook

No bot to invite, no OAuth dance, no token with broad scopes. A webhook URL is all Gabier needs, and it can post to both at the same time. Every channel receives every event; filtering happens upstream.

03 · Noise control

You decide what is worth a ping

By default only accepted logins get through: the one event that matters on a personal server. Turn on failures when you are hunting a brute-force, turn on disconnects when you want the full session story. Your own static IP and your cron accounts go in ignore lists, so the channel stays quiet when it is you.

[events]
accepted     = true
failed       = false   # noisy on port 22
disconnected = false
ignore_users = ["backup", "deploy"]
ignore_ips   = ["203.0.113.7"]
[Service]
DynamicUser=yes
SupplementaryGroups=systemd-journal
ProtectSystem=strict
ProtectHome=yes
NoNewPrivileges=yes
CapabilityBoundingSet=
RestrictAddressFamilies=AF_INET AF_INET6 AF_UNIX
MemoryDenyWriteExecute=yes
04 · Hardened

Least privilege, out of the box

A tool that watches your logins should not be a new way in. The shipped unit runs Gabier as a throwaway dynamic user with a read-only filesystem, no home, no capabilities and no executable memory. It can read the journal and open outbound HTTPS. That is the whole attack surface.

05 · Footprint

One static binary, a few megabytes

Rust, rustls, no OpenSSL, no runtime. Copy the binary to any Linux box with sshd and systemd (or a log file) and it runs. Idle, it sits on a journal pipe and costs nothing.

What Gabier will not do

Block anyone

It watches and reports. Banning is fail2ban's job, and the two run well side by side.

Store history

Your journal already does. Gabier keeps no database and no state across restarts.

Phone home

The only outbound connections are the webhooks you configured. No telemetry, no update check.
