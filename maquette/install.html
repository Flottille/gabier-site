Install

Two minutes to a running lookout.

Pick how you want the binary, paste one webhook, enable the service. Pince takes it from there.

Linux x86_64 · aarch64 systemd or a log file root for /etc and the unit
Step 1

Get the binary

Three ways, same result: /usr/local/bin/gabier.

cargorecommended
$ cargo install gabier
$ sudo install -m755 \
    ~/.cargo/bin/gabier /usr/local/bin/
Needs Rust 1.75+ on the box.
prebuilt
$ curl -LO https://github.com/[TON_USER]/gabier/\
    releases/latest/download/gabier-x86_64-linux.tar.gz
$ tar xzf gabier-*.tar.gz
$ sudo install -m755 gabier /usr/local/bin/
Static musl build. No Rust needed.
from source
$ git clone https://github.com/[TON_USER]/gabier
$ cd gabier && cargo build --release
$ sudo install -m755 \
    target/release/gabier /usr/local/bin/
Read it first, then build it.
Step 2

Create a webhook and the config

Discord: channel settings → Integrations → Webhooks → New webhook. Copy the URL.

Slack: api.slack.com/apps → your app → Incoming Webhooks → Add New Webhook to Workspace. Copy the URL.

Then generate the config, lock it down and paste the URL in. One of the two sections is enough; both is fine.

shell
$ sudo mkdir -p /etc/gabier
$ gabier init | sudo tee /etc/gabier/config.toml >/dev/null
$ sudo chmod 600 /etc/gabier/config.toml
$ sudoedit /etc/gabier/config.toml   # paste webhook_url
$ sudo gabier check
$ sudo gabier test                    # Pince waves hello
shell
$ sudo curl -o /etc/systemd/system/gabier.service \
    https://raw.githubusercontent.com/[TON_USER]/gabier/main/gabier.service
$ sudo systemctl daemon-reload
$ sudo systemctl enable --now gabier
$ systemctl status gabier
● gabier.service — Gabier
     Active: active (running)
     gabier: Gabier est dans la hune  hostname=vps-01 canaux=["discord"]
Step 3

Enable the service

The unit is hardened: dynamic user, read-only system, no capabilities, journal access through the systemd-journal group. It restarts on failure after five seconds.

Now log in over SSH from another machine. Your channel should light up within a second.

Upgrade

$ cargo install gabier --force
$ sudo install -m755 ~/.cargo/bin/gabier /usr/local/bin/
$ sudo systemctl restart gabier

Config keys are never removed within 0.x; new keys always have a default.

Uninstall

$ sudo systemctl disable --now gabier
$ sudo rm /etc/systemd/system/gabier.service \
    /usr/local/bin/gabier
$ sudo rm -r /etc/gabier   # holds your webhook

Nothing else is written anywhere. Pince leaves no footprints.
